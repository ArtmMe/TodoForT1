
# Менеджер задач для T1

## 🌿 Ветки проекта
- **`main`** - соответствует первому заданию (базовая реализация)
- **`Task2`** - соответствует второму заданию (расширенная версия с бэкендом, https://todo-for-t1.vercel.app/)

## 🛠 Технологии

### Ветка `main` (первое задание)
- **React + TypeScript** 
- **React Router**
- **Сборщик: Vite**
- **UI-фреймворк: Mantine**

### Ветка `Task2` (второе задание)
- **React + TypeScript**
- **State-менеджер: Zustand**
- **Маршрутизация: Tanstack Router**
- **Сборщик: Vite**
- **UI-фреймворк: Mantine**
- **Бэкенд: Express.js + Supabase** ([репозиторий](https://github.com/ArtmMe/todoserver))
- **Архитектура: FSD**

## ✨ Возможности

✅ Удаление задач  
📱 Адаптивный интерфейс для всех устройств  
🔍 Фильтрация задач 

## 🚀 Запуск проекта
1. Перейдите в директорию проекта
2. Установите зависимости
```bash
npm install
```
3. Запустите приложение в режиме разработки:
```bash
npm run dev
```
Или соберите production-версию:
```bash
npm run build
npm run preview
```
